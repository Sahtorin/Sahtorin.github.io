In order to make this website as accessibility friendly as possible, I will implement several features to ensure that users can navigate and interact with information provided on each page as effectively as possible. This means using colors that contrast easily for users with visual impairments, providing as many visual aids and descriptions as possible, making sure each picture comes with a description, using written and visual aids for the information that is important, and even taking into consideration the positon of the links that allow one to go from page to page. I will also make the written content on each page of my websute as clear and consice as possible, and will make sure that the information is organized in a way that is easy to follow.
